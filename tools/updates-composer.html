WXPN app updates

Write the banner and live-video messages the app shows, then publish them with Publish below: it saves the file the app reads to GitHub, and the app checks it every few minutes, so changes appear without an app update.

App switches

Publish

Publishing saves the file to the app’s GitHub repository. You see what changes first, and nothing goes out until you say so.

GitHub settings

Publishing needs a token: a password made just for this, which can only change files in the app’s repository. Make one on GitHub under Settings › Developer settings › Fine-grained tokens: choose Only select repositories and pick the repository below, then under Repository permissions set Contents to Read and write. Copy the token and paste it here.

The token is kept in this browser on this computer only, and sent only to GitHub. On a shared computer, use Forget token when you’re done. If it stops working (tokens expire), make a new one the same way.
