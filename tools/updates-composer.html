WXPN app updates

Write the banner and live-video messages the app shows, then publish the file below to the address the app reads (VITE_XPN_UPDATES_URL). The app checks it every few minutes, so changes appear without an app update.

        Times are entered in Eastern time. Only the first banner that is running shows, and the
        first live video; a live video takes over the banner while it is on. Notifications go only
        to listeners who turned them on in the app (Settings › From WXPN).
      

      

        Using Advanced Ads? Make one ad per message in the app’s ad group, paste
        what “Copy for Advanced Ads” copies as the ad’s content (a plain-text ad, or the code
        editor), and set the ad’s start and expiry dates. A banner with no notifications can also be
        a plain message whose link is the button.
